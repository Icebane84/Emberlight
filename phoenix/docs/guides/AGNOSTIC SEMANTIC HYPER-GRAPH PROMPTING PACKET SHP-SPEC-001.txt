STRATEGY 3: DECLARATIVE STATE-TRANSITION DSL SINKS
--------------------------------------------------------------------------------
To prevent complex branching control flow (deeply nested if/else or switch trees) 
from degrading LLM reasoning accuracy, you must convert state machines, animation 
sequencing, and execution rules into immutable data lookup tables (DSL Sinks) 
frozen via immutability primitives (e.g., Object.freeze).

TEMPLATE:

 * @dsl-sink <TableName>
 * @node-id [SEC-XX-DSL]
 * @invariants Immutable frozen lookup matrix. Zero branch evaluation overhead.
 */

    "KEY_OR_STATE_1": Object.freeze({ paramA: value1, paramB: value2 }),
    "KEY_OR_STATE_2": Object.freeze({ paramA: value3, paramB: value4 })
});
//#endregion
