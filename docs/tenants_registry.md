## 🏛️ 7. Tenant Compliance Invariants (The 3 Golden Rules)

Every gameplay district adheres strictly to the **VSRP-001 Universal Module Standard**:

1. **Rule 1: Isolated Working Memory (Faraday Cage)**
   - Tenants operate inside their own private `sim` closure.
   - Direct access to `canonicalParty`, `canonicalGold`, or external module globals is strictly forbidden.
   - Ingested snapshots in `reset(snapshot)` are deep-cloned via `structuredClone()`.
2. **Rule 2: Canonical 9-Method Interface**
   - Every tenant implements: `configure()`, `init()`, `reset()`, `update()`, `render()`, `getState()`, `getDiagnostics()`, `getModuleInfo()`, and `destroy()`.
3. **Rule 3: Sealed Envelope Communication**
   - State changes leave the tenant only upon resolution via `hostContext.eventBus.publish('<district>:resolved', envelope)` or host command dispatch (`system:command`).
   - Host runtime validates and merges the delta envelope into the authoritative Single Source of Truth (`EmberlightSessionStore`).
